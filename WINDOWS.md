# Recipe Studio на Windows

## Что нужно отправить другу

1. `RecipeStudio-Windows.zip` — сама программа (собирается командой
   `python package_windows.py`).
2. `embeddings.db` — база для поиска по эмбеддингам (можно отдельно).
3. Папку `icon-exports-x32` целиком — из неё строится каталог предметов
   (можно отдельно). Иконки выгружаются модом IconExporter в размере 32×32.

Без папки с текстурами программа запустится, но палитра предметов будет
пустой. Без `embeddings.db` останутся только локальные режимы поиска `S` и
`F`, а режим `E` будет недоступен.

## Куда это положить

Распакуй `RecipeStudio-Windows.zip` и положи данные рядом с папкой
`RecipeStudio`:

```
RecipeStudio-Windows\
    start_recipe_studio.bat
    RecipeStudio\
        ...
    embeddings.db
    icon-exports-x32\
        ...
```

`embeddings.db` должен лежать именно в корне распакованной папки, а не внутри
`RecipeStudio`. Папку `icon-exports-x32` нужно распаковать целиком, не
переименовывая.

## Запуск

Дважды щёлкни `start_recipe_studio.bat`.

При первом запуске нужен интернет: скрипт поставит `uv`, затем `uv` скачает
Python 3.14 и зависимости (примерно 150–250 МБ). Это происходит только один
раз. Дальше приложение запускается без интернета.

Если Windows покажет предупреждение SmartScreen, нажми
«Подробнее» → «Выполнить в любом случае».

Если `uv` не установился автоматически, поставь его вручную:
<https://docs.astral.sh/uv/getting-started/installation/>

## Поиск по эмбеддингам

Режимы `S` (substring) и `F` (fuzzy) работают полностью локально.

Режим `E` (embeddings) требует локальный OpenAI-совместимый сервер
эмбеддингов на `http://127.0.0.1:9931/v1` с моделью `embeddinggemma2`.
Наличие только `embeddings.db` недостаточно: база хранит векторы, но запрос
тоже нужно превратить в вектор на этом сервере. Без сервера `E` покажет
ошибку, а `S`/`F` продолжат работать.

## Если друг играет в тот же модпак

Можно распаковать папку в
`...\minecraft\scripts` (рядом с `mods` и `kubejs`). Тогда программа сможет
пересобрать кэш названий предметов из его собственных jar-файлов. Если папки
`mods`/`kubejs` нет, останется кэш названий, вложенный в архив, — он уже
содержит названия из этого модпака.

## Где хранятся настройки

- `RecipeStudio\config.json` — пути и параметры.
- `RecipeStudio\data\names_cache.json` — кэш названий предметов.
- `RecipeStudio\data\favorites.json` — избранное (создаётся при первом
  добавлении).
